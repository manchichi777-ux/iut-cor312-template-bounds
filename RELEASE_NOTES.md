# v1.0 — Public discussion draft

First public discussion version of *Template Bounds and Recovery Obligations for IUT III, Corollary 3.12*, by manchichi (pseudonym).

The paper establishes conditional template bounds and a recovery criterion within an explicit comparison system. It distinguishes those results from the unresolved correspondence with the actual IUT algorithm. It neither proves nor refutes Corollary 3.12.

The release includes the PDF, self-contained LaTeX source, and a text companion. AI assistance and verification limitations are disclosed in the paper and README.

Comments are welcome through repository Issues or at manchichi777@gmail.com. Please include the version, page, statement, and proposed correction.
