## What this is

This paper studies an explicit comparison system motivated by the log-volume comparison in IUT III, Corollary 3.12. It proves conditional bounds for a template region, isolates membership and coverage obligations, and separates the computed template contribution from an unresolved recovery contribution. It proves that, in the standard realization of Mochizuki's group Ism, the finite-place part of the second indeterminacy acts by unit scalars. A sensitivity result determines the hull that would result if this action were enlarged to factorwise lattice automorphisms.

## Scope and status

This is neither a proof nor a refutation of Corollary 3.12. The results are proved for an explicit comparison system; whether that system describes the actual IUT algorithm is the main open question (Section 7.3 of the paper).

Drafting and review were assisted by AI systems under the author's direction. The paper has not been reviewed by an IUT specialist and has not been formally verified.
